# Pontual Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** App Android local de ponto pessoal: batida em um toque dentro da janela 07:55–18:05, saldo contra 6h/dia, recesso proporcional, entrada manual só para esquecimento e backup em JSON.

**Architecture:** Um único módulo `app`. `calc/` é Kotlin puro (sem Android) com todas as regras de tempo; `data/` tem Room + `PontoRepository`, que aplica as regras de escrita em transações; `backup/` serializa/restaura; `ui/` tem uma pasta por tela com ViewModel + Compose. DI manual via `AppContainer`. Tempo sempre via `java.time.Clock` injetado.

**Tech Stack:** Kotlin, Jetpack Compose (Material 3), Navigation Compose, Room (KSP), kotlinx.serialization, kotlinx.coroutines, JUnit4, Robolectric, kotlinx-coroutines-test.

**Spec:** `docs/superpowers/specs/2026-11-13-ponto-design.md`

## Global Constraints

- Pacote base: `com.gabbzin.pontual`. Projeto Android na raiz do repo, módulo `app`.
- `minSdk 26`, `compileSdk`/`targetSdk 37` (plataforma instalada: `~/Android/Sdk/platforms/android-37.0`), JDK 17.
- Gradle 9.8.2 (já em cache em `~/.gradle/wrapper/dists`); AGP mais recente estável compatível com ele. Versões em `gradle/libs.versions.toml`.
- `local.properties` com `sdk.dir=/home/gab/Android/Sdk`, no `.gitignore`.
- Defaults de `Settings`: `dailyMinutes = 360`, `workdays = MON..FRI`, `windowStart = 08:00`, `windowEnd = 18:00`, `toleranceMinutes = 5`, `zoneId = America/Sao_Paulo`.
- Todo instante gravado em UTC (epoch millis); toda divisão por dia usa `Settings.zoneId`, **nunca** `ZoneId.systemDefault()`.
- Nenhuma chamada a `Instant.now()`/`LocalDate.now()` sem passar o `Clock` injetado.
- Textos de UI e mensagens de erro em português.
- Sem rede: o app não declara `INTERNET`.
- Comando de teste: `./gradlew :app:testDebugUnitTest` (todos os testes são JVM; Room via Robolectric).
